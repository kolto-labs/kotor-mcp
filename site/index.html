[ 03 · PROMPT COOKBOOK ]

Ready-to-copy prompts that get sharp answers

Pick a task, copy the prompt, and drop it into Claude, Gemini, ChatGPT, or Cursor.

1. Name the ResRef or module

Say “search .dlg resources in danm13” rather than “search all BIF files” so the model narrows before grepping.

2. Ask for which before cat

A ResRef can live in Override, a .mod, and chitin.key at once. Confirming precedence first prevents reading the wrong copy.

3. Request gron for field paths

gron output prints every field path on its own line (like EntryList[4].Text), making mod edits and changes.ini entries exact.

[ 04 · TOOLS, PLUGIN & FORMATS ]

7 read-only MCP tools & 12 decoded Odyssey formats

Every kq_* MCP tool runs the same decoder and index cache as the kq CLI, capped safely at 200 KB per response so it never floods your context window.

Want built-in KotOR workflows, not just raw tools?

Claude Code and Cursor users can install the full kq plugin from this repository. It bundles the MCP server with five domain skills and an isolated kq-explorer subagent for multi-module quest tracing.

kq-query Resolves targets, narrows before grepping, enforces which before cat.
kq-formats Interprets GFF, 2DA, TLK, NCS, BWM, and MDL paths accurately.
/kq:review Audits a mod or Override folder for shadowed files and broken refs.
/kq:merge-mods Three-way field/row merge of two mods against vanilla base files.
Format Extensions Decoded text output
